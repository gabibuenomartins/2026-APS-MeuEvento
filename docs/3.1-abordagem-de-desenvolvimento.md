# 3.1 Abordagem de Desenvolvimento

O projeto segue uma abordagem iterativa e incremental. As seções do documento serão produzidas aos poucos, seguindo a ordem proposta no projeto e acrescentando novas partes conforme o desenvolvimento avançar.

A abordagem aparece no projeto por meio da construção gradual do MeuEvento. Ao final de cada ciclo, uma parte do projeto será produzida e conferida com as seções anteriores, mantendo uma versão atualizada no repositório. Conforme cada etapa ficar pronta, ela poderá ser apresentada ao cliente para verificar se está de acordo com a proposta do sistema.

Essa abordagem foi escolhida porque permite desenvolver o projeto aos poucos e corrigir problemas antes de avançar para as próximas etapas. Diferentemente do modelo em cascata, não será necessário esperar que todo o projeto esteja definido para verificar se as decisões estão adequadas. O projeto também não utilizará práticas do Scrum como divisão em equipe, papéis específicos e reuniões diárias, porque será desenvolvido individualmente.
