# 4.2.2 Modelagem de Casos de Uso

## Atores

**Organizadora da festa:** pessoa responsável pelo planejamento do evento, que utiliza o sistema para registrar e acompanhar as informações da festa.

## Casos de uso

| Caso de uso | Requisito funcional |
|---|---|
| Definir data e horário | RF01 |
| Organizar comidas e bebidas | RF02 |
| Organizar decoração | RF03 |
| Registrar atrações | RF04 |
| Acompanhar organização | RF05 |
| Organizar itens da festa | RF06 |

## Especificação do caso de uso: Definir data e horário

**Ator principal:** Organizadora da festa.

**Objetivo:** Registrar a data e o horário da festa no sistema.

**Pré-condição:** A organizadora possui acesso ao sistema.

**Pós-condição:** A data e o horário da festa ficam registrados no sistema.

### Fluxo principal

1. A organizadora solicita o registro da data e do horário da festa.
2. O sistema solicita as informações necessárias.
3. A organizadora informa a data e o horário.
4. O sistema verifica se as informações foram preenchidas.
5. O sistema registra a data e o horário da festa.
6. O sistema informa que o registro foi realizado.

### Fluxo alternativo

1. Antes de confirmar, a organizadora decide alterar a data ou o horário.
2. A organizadora informa os novos dados.
3. O sistema registra as informações atualizadas.

### Fluxo de exceção

1. A organizadora não informa a data ou o horário.
2. O sistema informa que os dados precisam ser preenchidos.
3. O registro não é realizado.

## Rastreabilidade

Os casos de uso foram definidos a partir dos requisitos funcionais RF01 a RF06 da seção 4.2.1. Cada requisito funcional possui um caso de uso correspondente.
